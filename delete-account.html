인연도因緣圖

계정 및 데이터 삭제

운영: sdongworks (문의: sdongworks@gmail.com)

1. 앱에서 직접 삭제 (가장 빠릅니다)

인연도 앱 → 오른쪽 위 설정 → 맨 아래 계정 및 서버 데이터 삭제. 즉시 처리되며 되돌릴 수 없습니다. "기기의 관계도·리딩도 함께 삭제"를 켜면 기기에 저장된 관계도까지 지우고 처음 상태로 돌아갑니다.

2. 앱을 지웠거나 접근할 수 없다면

sdongworks@gmail.com으로 "인연도 계정 삭제 요청"이라고 보내주세요. 구글 계정을 연결하셨다면 그 구글 이메일로 보내주시면 본인 확인이 됩니다. 접수 후 7일 이내에 처리하고 회신드립니다.

3. 계정은 두고 데이터만 삭제하기

앱 → 설정 → 관계도 백업 → 서버 백업 삭제: 서버에 저장된 관계도 백업만 즉시 지웁니다. 계정과 코인은 그대로 남습니다.

초대 링크로 전달된 정보는 초대한 사용자가 회수하는 즉시 서버에서 삭제되며, 7일 안에 회수되지 않으면 자동으로 삭제됩니다. 그 밖의 데이터만 따로 지우고 싶다면 위 이메일로 요청해주세요 — 7일 이내에 처리합니다.

4. 계정 삭제 시 지워지는 것

서버에 저장된 코인 잔액·코인 내역, 관계도 백업(켠 경우), 초대 기록, 계정 자체. 연결된 구글 계정 정보도 함께 지워집니다.

5. 남는 것

기기에만 저장된 관계도는 서버 삭제와 무관하게 앱 삭제로 지워집니다 (앱에서 삭제할 때 "기기 데이터도 함께"를 켜면 같이 지워집니다). 가입 보너스 중복 방지용 기기 식별자 해시는 개인정보를 포함하지 않으며 남습니다. 이름이 제거된 익명 사주 구조 데이터로 생성된 리딩 캐시는 특정 개인과 연결되지 않습니다.

자세한 내용은 개인정보처리방침을 참고해주세요.
